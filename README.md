\# Voice Patient Simulator



A Python voice bot built on LiveKit Agents (pipeline mode: separate STT, LLM

and TTS) that phones a target line, plays a patient, and records and

transcribes each conversation.



\## How it works



`call.py` asks LiveKit to dispatch the agent with a phone number and a

scenario name. `agent.py` starts a voice session, dials the number through an

outbound SIP trunk, and plays the patient described in `scenarios.py`.

Each call is transcribed to `transcripts/` with timestamps. Audio is recorded

on both sides by the telephony provider.



\## Setup



1\. Python 3.10+, then:

&#x20;  ```

&#x20;  python -m venv .venv

&#x20;  .venv\\Scripts\\Activate.ps1      # Windows PowerShell

&#x20;  pip install -r requirements.txt

&#x20;  ```

2\. Copy `.env.example` to `.env` and fill in the values:

&#x20;  - `LIVEKIT\_URL`, `LIVEKIT\_API\_KEY`, `LIVEKIT\_API\_SECRET`: LiveKit Cloud project

&#x20;  - `OPENAI\_API\_KEY`, `DEEPGRAM\_API\_KEY`, `CARTESIA\_API\_KEY`: model providers

&#x20;  - `SIP\_OUTBOUND\_TRUNK\_ID`: the `ST\_...` ID of your LiveKit outbound SIP trunk

3\. Telephony: create a Twilio Elastic SIP Trunk with a termination URI and a

&#x20;  credential list, attach a voice-capable number, and add a matching

&#x20;  outbound trunk in LiveKit (address = the Twilio termination URI, same

&#x20;  credentials, your Twilio number). Turn on dual-channel call recording on

&#x20;  the Twilio trunk.



\## Run



In one terminal, start the agent and wait for `registered worker`:



```

python agent.py dev

```



In a second terminal, place a call (one at a time; wait for the first

terminal to print `session closed` before starting the next):



```

python call.py +1XXXXXXXXXX refill

```



Scenarios: `schedule`, `reschedule`, `cancel`, `refill`, `hours`,

`insurance`, `sunday`, `vague`, `change\_mind`, `unusual`.



\## Outputs



\- `calls/`: the 10 submitted calls, each as `call-NN-scenario.txt`

&#x20; (transcript) and `call-NN-scenario.mp3` (two-sided recording)

\- `BUGS.md`: issues found in the target agent

\- `ARCHITECTURE.md`: design choices and tradeoffs



\## Notes



\- Transcripts are generated by the bot's own speech-to-text, so a mistranscribed

&#x20; word can appear as an error. Anything reported as a bug was checked against

&#x20; the audio.

\- Recordings come from the Twilio trunk and were downloaded manually as MP3.

\- Calls 01 to 08 used Cartesia for text-to-speech. Calls 09 and 10 used OpenAI

&#x20; `tts-1` because Cartesia credits ran out. `agent.py` currently contains the

&#x20; OpenAI line; swap in `cartesia.TTS()` to reproduce the first eight.
